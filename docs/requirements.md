# 需求说明（阶段 5a）

本文档记录对 `external/task.md` 的理解，以及与用户确认过的决定。

## 1. 平台

| 项目 | 决定 |
|---|---|
| 语言 | Python 3.12（服务端），浏览器端为原生 HTML/JS（无构建步骤） |
| 依赖 | 安装在项目目录下的 `.venv`（`aiohttp`，测试用 `pytest`） |
| 监听地址 | `--listen IP` > 环境变量 `$ZEROTIER_IP` > `127.0.0.1`；端口 `--port`，默认 8000 |
| 登录 | 输入用户名；首次登录可设置密码（视为注册），密码可留空。同名再次登录 = 重连，接管原座位 |
| 会话 | 服务端签发 token，浏览器保存，刷新页面后自动重连 |
| 界面语言 | 中文 |

## 2. 房间

- 房号：4 位大写字母，创建时随机生成。
- 创建者为房主。房主可以：把空座位设为 AI、移除座位上的玩家/AI、开始游戏、回退、导出/导入 JSON、重新开始、关闭房间。
- 其他用户凭房号加入，自动坐到空座位；没有空座位则旁观（只看公开信息）。
- 多个房间可同时进行；同一用户可以在多个房间里有座位。
- 玩家掉线：座位保留，等待重连；房主可把该座位交给 AI。
- 服务器重启后，房间及其状态从磁盘（`data/`）恢复。
- 聊天：房间右下角的聊天框，房间里的人（包括旁观者）都可以发言，每条最多 300 字；每个房间保留最近 200 条，进入房间时看到之前的记录。聊天框默认收起，收起时显示未读数和最新一条。

## 3. 统一底层

- 所有游戏共享同一套状态结构：牌（静态属性）、牌区（带所有者和可见性）、公开变量、每个座位的私有变量、随机数状态、日志。
- 规则模块只需实现：初始化、当前谁需要做什么决定（可多人同时）、应用动作并校验合法性。
- 状态完整可序列化为 JSON：导出、导入、回退都基于它。随机数状态也在 JSON 内，回退后结果可复现。
- 信息遮蔽从第一版起实现：服务端持有全知状态，发给每个座位的是遮蔽后的视图（其他人的手牌只显示张数，不含牌的 id）。
- 回退：房主可回到任意历史状态，不对回退造成的信息泄露做特殊处理。

## 4. 红心大战（与 Windows XP 版相同）

- 4 人，人数不足由 AI 补齐（AI 默认名 Pauline、Michele、Ben）。
- 每局发 13 张，传 3 张牌，方向按 左 → 右 → 对家 → 不传 循环。
- 持 2♣ 者首先出 2♣。
- 必须跟花色；第一墩不能出分牌（红心、Q♠），除非手里全是红心或 12 张红心加 Q♠（此时可出红心）。
- 红心被打出后才算“破”；Q♠ 不破红心。红心未破时不能首出红心，除非手里只剩红心。
- 红心每张 1 分，Q♠ 13 分。一人拿到全部 26 分（射月）则自己 0 分、其他三人各 26 分。
- 有人累计 ≥ 100 分时游戏结束，分最低者胜（可并列）。
- 每局结束显示计分表（含历史），所有人确认后进入下一局。
- AI：一个难度，行为模仿 XP 电脑玩家（XP 源码未公开，采用启发式实现，只使用该座位可见的信息，不作弊）：
  - 传牌：没有足够小黑桃保护时传出 Q♠、A♠、K♠；传大红心；尽量清空短花色。
  - 出牌：能闷则用最大的闷牌；有更大黑桃在桌上时立即垫 Q♠；不持 Q♠ 时首出小黑桃逼 Q♠；缺门时先垫 Q♠、A♠/K♠、大红心。
  - 牌力很强时尝试射月；发现对手可能射月时，便宜的墩会主动吃一分阻止。
  - 实测（各 200 盘）：对 3 个随机玩家平均每局 1.5 分（对手约 8.5 分），胜率 96%；4 个 AI 互打每人约 6.6 分。

## 5. 城市交易所（阶段 5e）

已实现标准模式（3 人 / 4 人）、斗地主模式（3 人）、界面和 AI。按用户决定，规则书 3.2 之后的内容（3.3 角色技能、第 5、6 节的拍脑袋/待测试角色）不实现。

规则书没有写明的地方，按以下默认处理；带 ⚙ 的可以在房间选项中修改：

| 问题 | 默认 |
|---|---|
| 初始货币 | 0 元 ⚙ |
| 余额能否为负 | 罚款（点炮、出游）可以扣成负数；回购、强买默认不需要钱够（可设为需要）⚙ |
| 摸牌阶段特例 | Pattern 包含本回合摸的三张即可（可以带其他手牌）；计入本回合兑现次数 ⚙ |
| 出游 | 从下家开始按行动顺序轮流询问所有玩家（发动者排在最后），循环直到第一个不弃牌的人付 6 元 ⚙（关闭则只问一圈）；发动者自己不弃时付给自己，等于直接结束 |
| 兑现是否触发点炮 | 不触发 ⚙ |
| 点炮 | 被点炮的牌留在弃牌者的弃牌区；弃牌者付 1/3 给银行，兑现者从银行得 2/3；一张牌可同时完成同一人的多个 Pattern（手牌不能重复使用）；城市对也可以点炮 |
| 点炮时机 | 不阻塞游戏：弃牌后主玩家直接继续操作，能点炮的玩家同时可以点炮或不点，先到先结算（同一张牌可以被多人点炮）。机会在本回合结束时、或那张牌被强买/回购拿走时作废 |
| 点炮等待 | 每次弃牌（含出游弃牌；兑现可被点炮时也算）之后 3 秒内，所有人只能点炮，不能做别的操作 |
| 长考 | 除弃牌者外每人对每次弃牌可以长考一次，不管能不能点炮都可以点（不泄露信息）；之后最多 30 秒内其他人只能点炮，直到长考者点炮、不点、做别的操作或结束长考；同一时间只能有一人长考；那张牌不能再被点炮时不能长考 |
| 点炮信息 | 谁能点炮不公开：别人只看到自己的点炮提示，看不到别人有没有点炮机会（“思考中”只标正常流程里该行动的人） |
| 强买 | 可以买自己弃牌区的牌 ⚙（付给自己的 4 元相抵）；四人局一次最多买 2 张，可来自不同玩家 |
| 三人局多余的特殊牌 | 1 张周游列国、2 张强买放入除外区 |
| 被回购 / 强买的牌 | 所有人都看到它进入了谁的手牌（界面显示为“已知手牌”） |
| 游戏结束 | 回合结束时牌堆为空；手牌不计分；钱最多者胜，可并列 |
| 斗地主：没人当地主 | 所有牌洗回牌堆重新发，从下一位开始叫 |
| 斗地主：胜负 | 地主的钱 vs 两位农民的钱之和 ⚙（可改为三人各自比较） |
| 斗地主：农民共用 | 共用一个弃牌区和一张周游列国；回购可收回队友弃的牌；强买共用弃牌区的牌时，钱付给弃这张牌的农民 |
| 斗地主：点炮 | 弃牌者不扣钱，兑现者仍得 2/3；农民也可以点炮队友 |
| 斗地主：农民交牌 | 农民在回合结束时（手牌非空）把一张手牌交给另一位农民，只有交牌者知道是哪张 |
| 斗地主：“周游列国时二位农民每轮只需要选择一人弃置” | 只在地主发动周游列国时才有意义，而地主没有周游列国，所以暂未实现 |

AI：根据手牌“潜力”（每个 Pattern 的价值按还缺几张打折求和）决定弃牌；能兑现就兑现；回购或强买一张牌能立即组成 Pattern 且划算时就买；点炮时选择收益最大的可同时成立的组合；出游时弃牌损失小于罚款就弃，否则付钱；最后一轮使用周游列国。实测对随机玩家胜率 3 人局 98%、4 人局 96%。

## 6. 骗人游戏（`external/liar_game.txt`）

2–8 人。规则文件没有写明的地方，与用户确认后按以下处理；带 ⚙ 的可以在房间选项中修改：

| 问题 | 处理 |
|---|---|
| 牌 | n 副牌 ⚙（默认 1），每副带若干张王 ⚙（默认 2），王可当任何数字；尽量均匀地发完 |
| 每次出几张 | 至少 1 张 ⚙（原文写 >1，按至少 1 张理解；可设为至少 2、3 张）；没有上限。定数字的人牌不够时可以全部打出 |
| 一轮的第一手 | 定数字的人必须出牌，不能 pass |
| 可以质疑哪个声明 | 本轮最新的声明；中间有人 pass 也可以质疑，直到有人做出新的声明 |
| 翻几张、翻哪些 | 全部，或 1/3 上取整 ⚙；部分翻开时由质疑者点选。打出的牌在桌上随机排列，位置不透露信息 |
| pass 之后 | 本轮不能再出牌，也不能质疑；新一轮开始时清除 |
| 赢家已出完 | 由他之后顺时针第一个还有牌的人定数字并先出 |
| 出完 | 手牌为空且最新声明不能再被质疑时（有人做出新声明、本轮无人质疑而结束、或质疑失败）才算出完，按顺序排名 |
| 只剩一人 | 只剩一个人没有 pass 时，本轮立刻结束（包括有人出牌让上一个人出完、桌上只剩他自己的情况） |
| 可见信息 | 每次出的张数、声明、各人手牌数公开；被翻开的牌所有人都看到，并知道它进了谁的手牌；没翻开的牌只有收下的人看到；弃牌堆背面朝上 |

AI：只用自己能看到的信息。定数字时选手里最多的数字并打出；跟牌时打出真牌，没有时偶尔虚张（本轮已声称的数量接近总数时不冒险）；声称数量超过可能存在的数量时必定质疑，否则估计声明为真的概率（定数字的人按自己的牌选数字，所以首手更可信；跟牌按“从看不见的牌里抽到这么多”的概率，再考虑大家通常有牌才出），结合桌上张数、对方是否要出完决定是否质疑。600 局全 AI 对局全部正常结束，平均约 25 轮。
